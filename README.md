# Nearby Help

A mobile-friendly local services directory prototype built with plain HTML, CSS, and JavaScript. It is designed for static hosting on GitHub Pages.

## Run locally

Open `index.html` in a browser for the directory and profile preview. Progressive web app installation and offline caching require serving the files over HTTPS or localhost.

## Deploy with GitHub Pages

1. Put these files at the root of a GitHub repository, or choose this folder as the publishing source using GitHub Actions.
2. In the repository, open **Settings → Pages** and select the branch and folder you want to publish.
3. Wait for the Pages URL to become available. Open it on a phone and use the install directions in the app.

The sample worker profiles are fictional. The profile form is a local preview only. There is no database, shared profile submission, account system, or contact flow yet. Add a backend and obtain consent before publishing real people's information.
